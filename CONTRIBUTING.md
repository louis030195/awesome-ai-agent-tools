# Contributing

Thanks for considering a contribution! This list stays useful only if it stays current and high-signal.

## Guidelines

- **One PR per addition** (or a small, related batch) — makes review easy.
- **Alphabetical order** within each category.
- **Format**: `- [Name](link) - One sentence description, no marketing fluff.`
- **No self-promotion sprees.** One tool from your own org is fine; a batch of five is not.
- Check the project is still maintained before adding it (look at recent commits).
- If a linked project becomes unmaintained or archived, please open a PR removing it or flagging it.

## Adding a new category

Open an issue first to discuss — categories should reflect a real, distinct part of the agent-tooling landscape, not just a repackaging of an existing one.

## Code of Conduct

Be respectful. Disagree on merits, not on people.
